# busk.co

**Before the stadium lights, there was the street.**

A celebration of the musicians, comedians and performers who started from nothing — busking for coins before the world heard their name.

## The Site

Single-page HTML (`index.html`) — self-contained, no build step required. Open in any browser.

**Sections:** Hero → Stats → Famous Buskers Grid → Stories → Why Busking Matters → Submit a Busker → Footer

**Stack:** Pure HTML/CSS, Google Fonts (Playfair Display + Inter), vanilla JS for scroll effects. Zero dependencies.

**Color palette:** Dark charcoal (`#0C0A07`) + warm amber (`#D4891E`) + ivory (`#F8F4EC`)
